# Орбита

- `app/` Android-приложение (Kotlin, Jetpack Compose)
- `server/` сервер (Node 22, без зависимостей)

## Как получить APK через GitHub
1. Создайте на github.com пустой репозиторий (Private).
2. Загрузите в него все файлы из этого архива (Add file → Upload files), включая папку `.github`.
3. Откройте вкладку Actions → Build APK → Run workflow (или она запустится сама после загрузки).
4. Через 5–10 минут откройте завершённый запуск и скачайте `orbita-debug-apk` из Artifacts. Внутри `app-debug.apk`.
5. Передайте файл на телефон и установите (разрешите установку из неизвестных источников).
6. Если сборка упала, откройте лог и пришлите текст ошибки.

## Сервер
Телефон должен достучаться до сервера, поэтому его нужно запустить на хостинге/VPS: `cd server && npm start`.
Адрес сервера вводится на экране входа приложения (по умолчанию http://10.0.2.2:8080 — это эмулятор).
Пока приложение в бете, соединение без HTTPS; перед публичным запуском нужен домен и HTTPS.
